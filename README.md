# Java OOP Practice

A curated collection of small Java projects for practicing object-oriented programming. Each project is self-contained, so it can be opened and explored independently.

## Projects

| Project | Focus |
| --- | --- |
| [Core OOP Practice](projects/core-oop-practice) | A set of exercises exploring classes, interfaces, inheritance, registries, and related OOP fundamentals. |
| [Alarm Clock](projects/alarm-clock) | A console alarm clock using `Runnable`, time parsing, threads, and the Java Sound API. |
| [Data Structures](projects/data-structures) | A runnable fixed-capacity stack implementation demonstrating push and pop operations. |

## Repository layout

```
projects/
  core-oop-practice/   # original collection of OOP exercises
  alarm-clock/         # console alarm-clock project
  data-structures/     # standalone data-structure exercises
```

## Getting started

Open an individual project folder in your IDE, select a JDK, then run its main class. The alarm clock includes its own setup notes in [its README](projects/alarm-clock/README.md).

## Housekeeping

IDE configuration, compiled output, and local audio files are excluded from version control. This keeps the repository portable and centered on the source code.
